# GOK 文案包装校对

GOK 各系统与活动的文案包装评审网页。采用单文件静态 HTML，无构建步骤、无第三方脚本依赖。

## 使用

下载 `index.html` 后可直接用浏览器打开，或使用 GitHub Pages 发布 `main` 分支根目录。

- 切换系统与活动；当前收录妃子星命。
- 按明确错误（红）、概念歧义（橙）、表达优化（蓝）筛选。
- 查看文档页签、单元格、原文、替换方案及修改理由。
- 单独查看玩家介绍、内部核心体验和剧情。
- 搜索、复制、打印以及 JSON 导入导出。

## 追加评审

网页内提供数据模板。导入仅保存于当前浏览器，不会自动同步到仓库或其他设备。发布更新时，应将确认后的数据合入 `index.html` 中的 `review-data`，再提交到仓库。导出可用于备份与迁移。

所有文本均为建议稿；标记待确认的规则不代表已定稿。原工作簿未被修改。
