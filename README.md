# GOK 文案包装校对

GOK 各系统与活动的文案包装校对网页，使用单文件静态 HTML，无需构建。

## 内容

- 主题与概念：主题设定、系统命名、概念关系和内部核心体验。
- 功能文案：玩家介绍、按钮、提示、道具描述、属性说明及功能定义一致性。
- 剧情文案：角色对白、旁白、引导情境及完整剧情建议。

各类独立展示原文、文档位置、修改方案和理由。明确错误标红、概念歧义标橙、表达优化标蓝。支持系统与活动切换、分类筛选、搜索和复制。

## 更新

后续内容直接更新 index.html 中的 review-data 后提交。页面不提供导入导出功能，不使用浏览器本地存储覆盖仓库数据。

GitHub Pages 使用 main 分支根目录。所有方案均为评审建议，不代表原工作簿已修改。
